- I build web products end to end: interface, API, data and payments.
- I work on AI systems, with a focus on voice-first agents and applied machine learning.
- Recent work: **Fastask**, a marketplace that connects customers in Accra with verified artisans (Next.js, TypeScript, Express, MongoDB).
- I care about software that works on slow networks and low-end phones.
